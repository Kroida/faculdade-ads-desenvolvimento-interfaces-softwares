Aprendendo as chamadas CSS

Selecionando um elemento pelo ID

Para selecionar um elemento HTML pelo ID, basta colocar o símbolo "#" seguido do ID correspondente.

Selecionando pela class

Para selecionar um elemento HTML pela classe, basta colocar o símbolo "." seguido do nome da classe.

Selecionando pelo nome da tag

Para estilizar um elemento HTML, basta informar o nome da tag.

Formas de escrever o CSS

Existem 3 formas de escrever nossos códigos CSS: em um arquivo externo, dentro da tag STYLE no HTML, ou diretamente no atributo de uma tag.
