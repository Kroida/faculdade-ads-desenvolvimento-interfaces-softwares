# Guia de Navegação - Desenvolvimento e Interfaces de Software

Este guia apresenta um resumo das aulas e atividades avaliativas, destacando os conceitos e técnicas aprendidas em cada etapa do curso.

---

## **Aulas**

### **Aula 02: Introdução ao HTML**
- Estrutura básica do HTML (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
- Hierarquia de títulos (`<h1>` a `<h6>`).
- Parágrafos (`<p>`) e quebras de linha (`<br>`).
- Formatação de texto (`<strong>`, `<em>`).
- Uso de `<div>` para organização de conteúdo.
- Links (`<a href>` e `target="_blank"`).
- Listas ordenadas, não ordenadas e de descrição.

### **Aula 03: Trabalhando com Imagens e Links**
- Inserção de imagens (`<img>`), atributos `src`, `alt`, `width`, `height`.
- Links internos e externos.
- Estruturação de sites com múltiplas páginas.

### **Aula 04: Links Internos e Tabelas**
- Navegação interna com `id` e `href="#id"`.
- Criação de tabelas (`<table>`, `<thead>`, `<tbody>`, `<tfoot>`).
- Atributos `rowspan` e `colspan`.

### **Aula 05: Introdução ao CSS**
- Formas de aplicar CSS (externo, interno, inline).
- Seletores CSS (tag, ID, classe).
- Propriedades de cores, fontes e transformação de texto.

### **Aula 06: Blocos, Listas e Alinhamento**
- Diferença entre `<div>` (bloco) e `<span>` (inline).
- Listas personalizadas (`list-style-type`, `list-style-image`).
- Alinhamento de texto (`text-align`, `vertical-align`).
- Uso de `word-spacing` e `letter-spacing`.

### **Aula 07: Blocos e Planos de Fundo**
- Uso de `<div>` para estruturação.
- Propriedades de fundo (`background-image`, `background-size`, `background-repeat`).
- Hierarquia de planos de fundo.

### **Aula 08: Bordas e Tipos de Exibição**
- Estilos de borda (`solid`, `dashed`, `dotted`, `double`).
- Tipos de exibição (`block`, `inline`, `inline-block`).
- Estruturação de colunas com `float`.

### **Aula 09: Posicionamento e Efeitos Visuais**
- Tipos de `position`: `static`, `relative`, `absolute`, `fixed`.
- Uso de `z-index` para controle de sobreposição.
- Criando elementos fixos na tela (`position: fixed`).

### **Aula 10: Overflows e Menus**
- Controle de excesso de conteúdo com `overflow` (`hidden`, `scroll`, `auto`).
- Criação de menus horizontais (`display: inline-block`).
- Uso de `box-shadow`, `hover` e gradientes.

### **Aula 11: Formulários HTML (Parte 1)**
- Estrutura de um `<form>` (métodos `GET` e `POST`).
- Inputs comuns (`text`, `email`, `number`, `submit`).
- Labels e placeholders.

### **Aula 12: Formulários HTML (Parte 2) e Tags de Layout**
- Inputs avançados (`password`, `file`, `color`, `date`, `radio`, `checkbox`).
- Tags semânticas de layout: `<header>`, `<nav>`, `<section>`, `<main>`, `<article>`, `<aside>`, `<footer>`.
